# Contributing

Issues, reproducible examples, and feedback are welcome.

Report suspected security problems privately as described in
[`SECURITY.md`](SECURITY.md), not in a public issue.

During the public alpha, please use issues to share bug reports and feedback.
We are not accepting pull requests for code or docs yet. We still need terms
that protect your credit and let us offer commercial licences. We will settle
those terms before accepting outside work.

Never submit customer content, private course exports, credentials, proprietary
source, or an audit report you are not authorized to share.
