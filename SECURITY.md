# Security

Praxity Check runs HTML and JavaScript from the packages it checks. Only run it
on packages you trust; it is not designed to contain deliberately malicious files.

Report suspected vulnerabilities through
[GitHub's private vulnerability form](https://github.com/Praxity/praxity-check/security/advisories/new).
Do not open a public issue or include private course or customer content unless
it is necessary, authorized, and safe to share.

During the alpha, security fixes apply to the latest version on `main`.
